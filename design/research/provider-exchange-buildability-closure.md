`planning/provider-exchange-and-execution/independent-buildability-review-2026-08-27.md`.

The amended candidate separates the previously collapsed identities: compiled-path identity is a
canonical occurrence-addressed digest; global reachability contains no subject-specific cache
claim; run/module/request availability is resolved for an exact server-owned subject; acquisition
evidence is immutable while delivery records live versus retained service; and engine pending keys
contain requested bytes while actual identity/generation enters only inside the serialized
exchange. `[V]` `rfc/provider-exchange-and-execution.md` §§1–4;
`tools/d1871-provider-exchange-amendment-harness/provider-exchange-contract.test.mts`.

The provider protocols are now closed enough to falsify lossy implementations. Maia preserves the

and incomplete root rows and owns a narrow capability-register migration. `[V]`
`rfc/provider-exchange-and-execution.md` §§5–8; the eight focused arms pass via
