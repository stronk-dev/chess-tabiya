# D3300 — output-preserving collector work reuse

Implementation correction within the existing longitudinal/collector contracts,
not a narrower evidence adapter or a new primitive. The complete population and
byte-equality requirements remain (`rfc/longitudinal-store.md` §B / rebuild contract).

## Changes and permanent controls

- `packages/runtime/src/square-control.ts`: a legal-alternative census repeatedly
  flattened the same before-position controller arrays into maps. One private
  entry now reuses that reading's at-most-four pseudo/legal indexes. It does not
  cache thousands of after-position maps. Changing the exact before reading
  replaces the entry; different clock fields do not alias. No map escapes.
- `packages/runtime/src/structure.ts`: structural comparison sorting repeatedly
  called `JSON.stringify` on the same observation. A decorate/sort/undecorate pass
  computes each key once, preserving the original kind order, `localeCompare`,
  stable ties and original observation objects. There is no global key cache.
- Eleven permanent `collector-index-reuse.test.ts` controls exercise both-colour
  serialization counts, index construction/replacement including clocks, an
  independent array/Set delta join, castling, en passant, promotion and unavailable
  check turn-clones. The old paths fail three controls: repeated serialization
  (three calls instead of one in the reported failures) and 16 rather than 12 maps
  after two alternatives. The repair passes all 74 focused checks and workspace
  types, with zero Svelte errors/warnings. No wall-clock assertion enters CI.
