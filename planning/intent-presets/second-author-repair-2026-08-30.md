# Intent presets — second author repair

- **Date:** 2026-08-30
- **Scope:** [[D2127]]–[[D2134]] only
- **Verdict:** author repair complete; fresh independent review still required
- **Production status:** unchanged; no preset implementation is authorized

The repair replaces three competing authorities with one staged contract. A strict v2 preference
receipt owns preset identity and sparse Advanced/Custom intent. The client can construct only an
untrusted request and browser-channel availability; the server re-derives context, access,
provider state, modules and effects, then seals requested/effective digests. The browser may only
narrow local speech output from that server result.

The v2 field image is closed over all nine assistance-head fields and has a fail-closed parser plus
canonical serializer. First load seals v2, valid or invalid v2 wins over legacy bytes, and every
production v1 writer is removed at implementation. Custom now carries explicit module
include/exclude deltas in addition to sparse field overrides, so a higher field cannot advertise a
module it never activates. Context, access, source and browser narrowing each emit a discriminated
suppression with exact requested/effective/reason bytes and deterministic rendering.

Source-sensitive effects do not use a second hand-maintained map. Their AND/OR alternatives derive
from the exact 205 module-binding rows and 117-operation execution/derivation DAG. `no_witness`
remains an honest-empty result; one failed alternative cannot suppress another live alternative;
mixed Inspector families retain independent local output when a provider is unavailable.

Campaign is not papered over. The context remains registered, but the seven ordinary contexts may
phase independently while Campaign returns `CONTEXT_DECLARED_AWAITING`. Only accepted and
implemented `campaign-core` may later supply the encounter receipt, issuer and verifier; this RFC
does not invent their bytes and cannot claim eight-context completion before that dependency lands.

Author-boundary verification:

- `make intent-presets-author-contract`: 7/7 green;
- `make intent-presets-second-author-repair`: 8/8 green, one arm for each returned row;
- the D2132 arm imports the module execution/binding artifacts and proves every binding resolves
  through the shared authority rather than a prose-only dependency claim.

This is not acceptance. Fresh review must attack strict parser closure, request/digest forgery,
server/client widening, Custom activation under ceilings, suppression completeness, derived source
alternatives, v1-writer retirement and Campaign refusal before implementation begins.
