## Actual execution, caches and clocks

Cold means an empty application dependency cache. Warm re-executes the same
case with its actual admitted dependency receipts available; it is not a cached
final answer or a second JSON parse. Record cache occupancy and every executed,
cached, unavailable, invalid or timed-out query. A warm available provider arm
must demonstrate actual cache hits. Offline starts with an empty cache and
denies all requested provider executions; no historical source is substituted.

Stockfish identity includes the actual binary/source digest, full FEN, exact
depth-8/depth-12/100-ms budget and MultiPV width. Do not mix budgets or coherent
search tables. Maia identity includes the actual model/adapter/configuration
digest, original root FEN, **ordered full path**, self/opponent band 1400,
temperature 0.8 and top-p 0.92. A shared resulting FEN is not a shared Maia query.
Pre-root history remains unavailable, exactly as in the corrected experiment.
Retain literal receipts and raw provider data for independent legality/identity
replay. Changed live ordering/mass must be reported as a fresh-source sensitivity,
never silently copied back into frozen semantic results.

Start the monotonic clock before this case's legal population, source dispatch,
collection and reason compilation; stop after its final typed server result.
Retain the full interval and source/collection/compile phase intervals. Phase
intervals may overlap but none may exceed the operation. Loading historical
research artifacts, enumerating a stored graph, adding historical query durations
or measuring a local compiler alone does **not** measure this interval.

Record machine/OS/Node/CPU, actual worker identities, concurrency, startup/readiness
cost and exact instrument/input digests in the batch envelope. Report retained
result bytes and process memory. Sampled RSS is a lower bound, not a true peak;
external process peak must identify which process it covers. Parent, engine and
model memory are separate observations, not an invented sum of coincident peaks.
First-use engine/model startup stays visible separately from request-ready cost.

The server receipt says `server_execution_only_not_browser_rendering`. It cannot
discharge the accepted Hint envelope. A subsequent actual browser request must
join request/decision/source identities, mandatory dependency resolution, first
honest output and visible registered output. The 1,500-ms and 150-ms gates remain
unchanged; neither a server duration nor a researcher-supplied pass boolean is
admitted as browser or physical-paint evidence. Existing shipping Hint measurements
are not a measurement of this draft search implementation.

## Executable falsifiers and current state

`make semantic-search-cost-contract` independently regenerates the expected plan
from its pinned comparison and reads it without rewriting. The row reader rejects
filtered, duplicate or foreign cases; crossed plan identities; missing raw receipts;
invented result/clock/memory scopes; cold/offline cache contamination; provider-off
execution/reuse; available results with failed or absent mandatory sources; wrong
provider families; FEN-only Maia shortcuts; source-free arms querying an engine;
warm results without warm dependencies; and incomplete reports called complete.

This is **structural admission**, not an independent witness that supplied clocks,
providers or browsers actually ran. Raw capture and independent execution/replay
are still mandatory. The positive unit rows are synthetic controls, never live
research results. No row exists from a live cost capture yet. No production budget,
profile, full D3262 discharge or 1.0 milestone is selected by this preregistration.
