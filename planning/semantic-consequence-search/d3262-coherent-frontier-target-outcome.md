# D3297 — corrected first-reply frontiers against one bounded target

Measured 2026-09-23 on the separately frozen coherent-root D3262 frame.
`make semantic-search-coherent-frontier-target-check` replays the checked
`d3262-coherent-frontier-target-outcome.json` artifact (SHA-256
`6c5dc6beb1e0904a80c766ba67cbd80db0cecc7840193658fd541def1d7a69db`).
This is a **first-reply pruning sensitivity**, not the predeclared full
five-arm proof/abstention/cost experiment or a production profile. `[V]`

The instrument joins all 182 named target/candidate cells, the same four
controls, the complete 6,176-edge exact reply graph, the checked bounded
target result, and separately frozen first-reply selections. For each cell it
evaluates 29 selected-reply sets: engine top 2/4/8 at three budgets, two
semantic one-slot reserve source widths at those nine settings, and configured
Maia 0.80/0.90 prefixes. It refuses crossed legal FENs, changed engine
baselines, missing cells, invalid selected replies and any partial result
stronger than its complete exact authority. The first-reply selected set is
the only arm-specific input to this calculation; deeper continuation uses
the **same exact evaluator**, not each arm's distinct provider traversal.
That boundary prevents this diagnostic from being misreported as a completed
arm-3/4/5 comparison. `[V]`

All nine engine settings and eighteen semantic settings are retained in the
artifact; this table shows representative widths, not a tuned winner. At
width eight the one-slot semantic reserve cannot add a reply outside the
top-eight baseline, and its outcomes match that baseline. At width two or
four the all-legal event reserve sometimes replaces a selected reply but
does **not** improve this held-out target result; at depth-12 top two it
loses two witnesses relative to the engine baseline. This does not refute
semantic targeting generally: the event identifies a typed relation, not
necessarily the particular future target outcome, and these selected cells
are not representative game frequencies. `[V]`

The depth-12 top-eight engine selector misses seven bounded reintroduction
cells: six named future-square arrivals and one material target. Configured
Maia also misses seven, but **not the same seven**; equal aggregate hit counts
do not make the selected reply policies interchangeable. Both miss one of the
eight existential preparations on this frame.
Only one to five cells per arm have a complete legal first-reply set. A
selected witness is a bounded, replayable existential fact; no selected
witness means **unknown over unvisited replies**, never “the opponent cannot
do it” or “this move is safe.” A found all-learner-defence preparation has
only that quantified meaning; it does not say every opponent reply forces
the target. `[V]`
