## What this does not establish

Every arm retains first-reply, learner-edge and final-reply omissions, plus terminal
absorption. All 4,914 target arms keep `abstain_from_partial_frontier` for a partial
negative and `not_evaluated` for universal proof. A visited opportunity or actual
execution is a line observation, not durable prevention, all-defence survival,
engine causality, a move grade or a useful proactive hint by itself.

This is the frozen **first-reply** reserve followed by ordinary engine selection,
not a recursively target-preserving search. Its failure to improve this reading
cannot be recast as proof that semantic search cannot help. The actual continuation
now makes the next comparison possible without borrowing the common exact evaluator
as though it were each arm's chosen learner/final move.
