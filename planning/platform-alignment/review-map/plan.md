# R7 grounded Review Map — research plan

**Status:** current-product audit implementing 2026-08-21

## Question

Can a bounded post-game map select a few grounded moments and turn each into a useful action—retry,
branch, compare, drill or cited theory—without reducing review to engine labels plus prose?

## Work units

1. Measure the shipped Story selector, provenance, private/public moment parity and action doors.
2. Compare the interaction contract against current Chess.com Game Review, Lichess Learn from Your
   Mistakes, BeaconChess and Quackmate sources already routed to R7.
3. Prototype one shared bounded-moment projection over exact F2 facts and existing recorded story
   facts. No product code and no new chess judgment.
4. Run the same fixed games through current Story and the candidate projection. Record moment volume,
   source mix, action availability and honest abstention.
5. Publish the O7 choice set: moment families, engine-label role, theory/human context, re-entry and
   share contract. Do not draft F6 before the R7 gate is met and the owner rules O7.

## Automatic failures

- private and shared recap choose different moments;
- a social artifact claims a source not present in its admitted evidence;
- a moment has no replay/branch/drill/theory action;
- an engine threshold silently becomes a move grade or best-move command;
- an LLM selects moments, changes their grounding or invents the link to theory;
- a fixed card count is filled with generic facts when fewer useful facts exist.
