# Foundation source identity — author repair

This pass repairs the five contradictions found by the same-day author audit. It is not the fresh
independent buildability review and authorizes no production, schema, content, API or UX change.
That review remains blocked until the semantic-convention register and provenance dependencies
land and the predeclared convention set can become a live checked claim.

## Repair result

1. **[[D2390]] — authority is now two typed sets.** Projection-plan schema v2 removes scalar
   `authority`. Every row carries `sourceDependencies` (typed projection/RFC prerequisites) and
   `conventions` (only semantic `id@version` refs). The backward-pawn consequence now preserves
   both its backward-pawn and legal-exchange conventions and both exact input projections. The
   future convention set is 12, ASCII-sorted, and every new base begins at `@1`; it remains a
   predeclaration, not an illegal live resource claim while the register is draft.
2. **[[D2391]] — clocks use an authenticating recorded decision.** A new grain binds run, event
   head, event, actor class, decision class and decision id. It carries no caller-written time.
   `recorded-clocks` alone resolves the event into typed readings/control or unavailable, so its
   returned state remains an explicit dependency instead of being simulated from a board edge.
3. **[[D2392]] — operation routing follows grain.** Both fianchetto rows remain reusable position
   facts and route through the shared candidate packet. Frozen-prefix state routes through the
   recorded path; recorded clock decisions route through `recorded-clocks`. Recorded occurrence
   context is a separate sealed operation envelope, not a second board scan or extra chess fact.
4. **[[D2393]] — style attribution fails closed.** All seven style rows declare
   `contextRequirement: actor_decision`. A `ContextualFoundationOccurrence` binds actor and
   decision identity/class, event head and the exact source-receipt digest before any history
   consumer. Bare or relabelled facts cannot enter learner history.
5. **[[D2394]] — successor transitions are total.** Opposition uses one five-case algebra with
   `membership_changed` for unequal present→present state. Backward-pawn matching first preserves
   unchanged exact subjects, then follows the edge's exact pawn from→to, then emits lost/gained for
   remaining rows; a matched changed row emits exactly one `membership_changed`.

## Executable author check

`make foundation-source-author-repair` runs the closed 23-row contract plus positive checks for all
five repairs. The historical audit dossier remains evidence of why the first pass was returned;
its executable now asserts the repaired bytes rather than requiring the repository to preserve a
known contradiction.

## Remaining boundary

The draft is author-repaired, not accepted. Fresh review must still rederive the 23 rows, 12 future
conventions, operation/context join and event algebra after the semantic register dependencies
land. Source implementation, value factories, validation, consumers and Gate-F content migration
remain separate able-to-fail stages.
