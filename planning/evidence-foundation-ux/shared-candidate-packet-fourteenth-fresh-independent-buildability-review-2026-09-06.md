# Shared candidate packet — fourteenth fresh independent buildability review

- Date: 2026-09-06

- Verdict: **RETURNED** on [[D3009]]–[[D3016]]
- Executable receipt: `make candidate-packet-fourteenth-fresh-review`
- Production effect: none; no packet, cache, selector, bot, hint, Review, schema or content

## What survived

The thirteenth repair closes its eight named seams. Collector memo images are dependency-limited,
invocation errors retain collector identity, abandoned work cannot be rejoined, request diagnostics
are separated, the manifest is not charged to every cache entry, legal/row/FEN joins are rechecked,
child-reading keys derive from the admitted catalogue, and the model compiles under the repository
TypeScript contract. This review retains those repairs.

## Fresh returns

1. **[[D3009]] hidden execution is public.** A readings-only receipt exposes
   `candidateInputs[].executionOutcomes`, including `event.transition` and `event.tactical`, even
   though §3.4 requires dependency-only execution to remain in the private reference authority.
2. **[[D3010]] factory authority is only a TypeScript shape.** The product factory accepts
   caller-supplied `manifest`, digest, collector and arbitrary extra fields after a double cast and
   starts a service. The RFC explicitly requires runtime refusal before job/cache construction.
3. **[[D3011]] failure vocabulary has three authorities.** Normative §3.1 has no
   `invalid_request` and attributes every collector failure to a projection; repair prose assigns
   invocation failures to collectors; the model carries both service forms and retains an
   unreachable packet-result `failed` arm.
4. **[[D3012]] receipt reconstruction stops early.** It does not recompute the scope plan, prove
   one execution result per output, prove exact retained membership, rebuild row event/reading
   views, or assert the converse unavailable-outcome↔abstention relation. Its crossing helper can
   exercise only legal identity, row identity and child FEN.
5. **[[D3013]] the measured graph is not the specified graph.** The model has no category census,
   no one-root descriptor and no private `WeakMap` retaining exact construction references; it
   returns only two totals after three separate root traversals. Cache bounds therefore cannot
   prove the root/category closure criteria.
6. **[[D3014]] scope correlation is erased.** Unlike the normative generic `get<S>`, the model's
   request/result/receipt types are non-generic. TypeScript cannot know that an `events` request
   yields an events-only receipt; the compile fixture retains this diagnostic until repaired.
7. **[[D3015]] collector failure is tested by manufacturing the answer.** The named private test
   seam accepts whole-compile and yield hooks only. Supplying a collector hook is ignored, so no
   throwing/malformed collector crosses the registry executor; the existing test throws the exact
   private error class it expects the service to map.
8. **[[D3016]] stats drifted from their closed contract.** Runtime and model type expose eighteen
   fields after adding two process-singleton measures, while the RFC interface and criterion 33
   still require exactly sixteen and do not name either field.

## Buildability consequence

The shared packet remains the right evidence denominator for Support, Review, bots and later
learner modelling, but this checkpoint is not a truthful implementation plan yet. It makes hidden
dependencies public, trusts product factory extras, cannot express scope narrowing, does not
independently close the graph it measures, and lacks a real collector fault boundary. Keep the RFC
in draft. The next bounded author repair must reconcile one normative type/runtime contract and
retain all prior repairs before another genuinely fresh review; the separate
`evidence-value-authority` dependency still precedes production implementation.
