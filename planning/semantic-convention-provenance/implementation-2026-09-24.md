## What shipped

- **Register (process, first commit).** `rfc/shared-resource-registers.json` gains the
  `semantic-conventions` `members` row over the existing `string_tuple` reader. The source
  `packages/runtime/src/evidence-conventions.ts#SEMANTIC_CONVENTION_MEMBERS` was created empty first
  so the resource was present and absent-source admission ([[D3082]]) was not needed; the README
  register opened at `members=0` with this RFC's 48-member claim.
- **Registry (product, second commit).** `CONVENTION_DECLARATIONS` holds 48 declarations. The first
  39 are generated byte-for-byte by `tools/generate-initial-convention-declarations.mjs` from the
  reviewed `initial-declarations.json` (`make semantic-convention-source-check`). Nine are authored
  beneath the generated region: `phase-bands@1`, `endgame-material-census@1`,
  `named-structure-catalogue@1`, and the six cited setup/method conventions moved out of
  `endgame-setup.ts`/`endgame-method.ts`. `testing/convention-bindings.ts` renders each authored
  declaration from the code that computes it, and the test requires byte equality.
  `compileConventionRegistry` orders, freezes and digests; it refuses duplicate/aliased/malformed
  refs, blank fields, unsupported or unresolvable authority and skipped lineage.
- **History.** `packages/runtime/src/evidence-convention-history.jsonl` has 48 canonical rows
  (`ref, semanticDigest, registryDigest, ownerRfc`, no self commit). `make
  semantic-convention-history-check` checks shape, lineage, digest equality with the declarations,
  and append-only bytes for the working tree against HEAD, the index against HEAD and HEAD against its
  first parent. Both checks are in `verify-governance`.
- **Closure.** `evidence-convention-closure.ts` derives each mintable projection's direct refs from
  declaration witnesses, successor retention, registered tokens in catalogue text and one declared
  inheritance row (`rules.square.event.control@1` ← `square-control@1`). The two instance
  projections (setup match, method stage) take only the convention a value was computed under.
- **Value receipt.** `evidence-factories.ts#mint` seals a `ConventionReceipt`
  (`refs, registryDigest, derivation, digest`) into every value receipt. A derived value's closure
  unions the exact sealed inputs' closures. Its derivation records the canonical used-input member
  and the multiset of input value digests; each input digest covers producer, projection, payload
  digest and that input's own receipt digest. `evidenceConventionReceipt(value)` reads it.
- **Consumers.** The `evidence-value-authority` D1 rows lose their `pending` notes, and the setup and
  method lookups resolve only registered refs. The recorded semantic path returns
  `{status: "registered", registryDigest, refs, eventReceiptDigests, digest}`, and its identity digest
  covers each event's receipt ([[D1921]]/[[D1929]]).

## Measured, not faked

§4 asks that the derived member resolve to exactly one *declared* manifest derivation member. I
instrumented the mint over the full runtime and server software suites. Production factories
legitimately mint from input subsets of the manifest's union members:

- `derived.story.rank@1` and `derived.story.title@1` use subsets;
- `derived.opponent.candidate_feature_vector@1` uses a vector of readings against per-pair members;
- the recorded readings use `sourcing.ledger.*` inputs that no member declares; and
- the forced mate and fork-survival rows use one input fewer.

Validation against declared members would therefore refuse real values. The receipt records the
exact used-input member instead, and the declaration reconciliation stays with the remaining §2
work.
