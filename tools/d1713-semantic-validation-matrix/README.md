# D1713 semantic-validation migration matrix

Disposable research instrument following [[D1711]]. It maps all 67 semantic projections to exact
existing executable authorities without treating a lower-level predicate test, an event-emitter
test, a population observation and an external-label disagreement study as interchangeable.

Run with pinned Node 24:

```sh
make semantic-validation-matrix
```

D4170's separate disposable actual-input experiment runs with `make semantic-input-order-research`.
It reports whether genuine factory input reversal is accepted, without registering a chess oracle
or treating declaration-family semantics as an input-identity proof. The same small instrument
also retains D4167's both-color genuine castle-alias source control: normalized payloads agree
while original factory-input digests differ. That is source normalization evidence, not a
completed semantic-wrapper or ordinary-consumer migration.


The matrix has six arms: event positive, semantic hard negative, orientation/mirror,
counterfactual/complete-alternative, imported population and external-labelled comparison. Each
claimed authority names an exact file and test case and fails if that case disappears. Empty means
“no existing executable authority established in this pass,” not “the event is false” or “the arm
must apply.” Required-versus-inapplicable is the semantic-validation RFC's total-table decision.


D4167/D4171–D4173's disposable composition and case-grammar measurements run with
`make foundation-shared-operation-research`. They compare existing factory payloads, invocation
sharing and current parser/witness semantics; they do not establish a new oracle, production
caller, performance budget or source qualification.
