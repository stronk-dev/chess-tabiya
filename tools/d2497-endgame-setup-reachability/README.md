# D2497 endgame setup reachability instrument

Disposable research code. It distinguishes a finite “within N plies” claim from an unbounded
reachability question explored with a finite operational budget. It verifies complete legal root
move sets against three dated Lichess tablebase snapshots, retains only exact beneficiary-WDL
preserving edges, and evaluates possible / forceable / inevitable with their proper game-tree
quantifiers.

It is not a production provider, a best-move selector, advice, or proof of eventual reachability.

Run through `make endgame-setup-reachability-contract`.
