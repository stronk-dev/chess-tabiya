# D1726 legacy-reading / identity-rich-successor closure

Disposable research instrument. It joins the complete legacy structural and transition reading
vocabularies to richer shipped projections, the compiled consumer graph, the live web operation,
and the returned module-registration table. It does not change a producer, consumer, RFC, pack or
learner surface.

```sh
/opt/homebrew/opt/node@24/bin/node node_modules/vitest/vitest.mjs run \
  --config tools/d1726-evidence-successor-harness/vitest.config.ts --reporter=dot
```

Set `D1726_CENSUS=1` to recompute the fixed authored/imported raw-reading census.
