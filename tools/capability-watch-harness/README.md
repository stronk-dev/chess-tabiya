# Capability-watch harness

Disposable planning/research instrument for D556. It validates the capability-first register and
writes a deterministic summary; it does not crawl the web or authorize product work.

```sh
node tools/capability-watch-harness/check.mjs \
  design/research/capability-watch.json \
  planning/platform-alignment/capability-watch/results.json
```

The checker binds referenced local evidence, canonical product identities, closed dispositions,
love/hate missingness, producer/consumer/route completeness and exact capability-map family names.
Its synthetic controls prove that product aliases do not increase capability coverage while a new
capability does.
