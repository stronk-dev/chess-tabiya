# R13 grounded-coaching harness

Disposable, read-only platform-alignment research. It audits current persistence reach, measures
pack-concept identity fragmentation and exercises a typed coaching-card contract with negative
controls. It does not create product schemas, choose defaults or judge chess moves.

Run only this focused instrument:

```sh
pnpm exec vitest run --config tools/r13-grounded-coaching-harness/vitest.config.ts
```

The test regenerates `prototype-output.md` from the current tree.
