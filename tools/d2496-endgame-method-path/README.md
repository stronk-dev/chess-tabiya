# D2496 endgame method/path instrument

Disposable research code. It recognizes only cited, source-bounded observed stage transitions on
an exact path and demonstrates that `possible`, `forceable` and `inevitable` are different bounded
game-graph claims. It is not production evidence code, advice, a best-move selector or a universal
definition of Lucena, Philidor or Vancura.

The contract also measures every authored root-to-leaf path in the current draft corpus and writes
the deterministic report to `planning/endgame-method-path/results.json`.

Run through `make endgame-method-path-contract`.
