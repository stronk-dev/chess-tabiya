# D1588/D1590 module-delivery boundary harness

Disposable research instrument for the returned `module-registration` RFC. It proves there is no
server route, client API operation or response type for module packets; pins the existing direct
board→drill→session commit chain; and demonstrates one generation-token staging handshake across
click, drag, touch, keyboard-grid and SAN/UCI text input.

The coordinator is a feasibility prototype, not production code. It deliberately leaves the
server request/wire/seat contract to the RFC amendment.

```sh
pnpm exec vitest run --config tools/d1588-module-delivery-harness/vitest.config.ts
```
