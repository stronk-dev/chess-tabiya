# D1717 king-opposition semantic boundary

Disposable research instrument. It compares the shipped alignment/parity/turn convention with an
unobstructed-line candidate over canonical fixtures and the fixed authored/imported populations.
It does not change the production predicate.

```sh
D1717_CENSUS=1 /opt/homebrew/opt/node@24/bin/node node_modules/vitest/vitest.mjs run \
  --config tools/d1717-king-opposition-harness/vitest.config.ts --reporter=dot
```

Default execution checks the frozen census and the canonical direct/distant, blocked, turn and
orientation matrix.
