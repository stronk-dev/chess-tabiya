# D1718 avoidance subject-identity census

Disposable research instrument for D1716. It replays the fixed authored and imported populations
through the production complete-alternative selector and measures whether the played child still
contains the selected avoidance family or the selected root-subject/predicate condition. Piece,
king and ray keys are projected back to the common root; file, square and aggregate families use
their declared dimensions. This is a diagnosis of the current receipt, not the proposed runtime
implementation.

Current counterexamples run through the normal repository toolchain, including their own strict
typecheck:

```sh
make avoidance-subject-measurement
```

The 2026-08-26 census is historical, not a current reading. Default execution checks its retained
receipt and the set-equal13-family grammar, the current incomplete original root, a complete
bishop-removed variant and the actual same-edge12-subject source. The variant observes the real
factory call/return without changing arguments, results or the top-two policy: a broad isolated-
pawn candidate is issued for all34 alternatives while the played pawn is isolated on another
file; the candidate is not selected. The old root now abstains because Bh7+ makes defender_exposure@2
unavailable. These are different stages, neither a claim that learner avoidance is enabled nor
that the semantic identity bug is repaired.

The expensive full census is explicitly skipped unless requested; this command does not recompute
or silently replace its frozen counts. This is disposable research, outside ordinary software CI,
with no production source, consumer, policy, budget, qualification or content change.

`current-source-abi.test.ts` adds twelve bounded controls for all thirteen source families:
file-state positives/negatives, material/island zeros and equality, sparse attack omissions,
strict-interior rays, moved slider/pawn identity, king-zone movement, blocked historical
opposition, and mover-only/non-king loose-piece values, both-false omission and unavailable evaluation. It does not recompute the corpus census,
implement total subject/outcome adapters, qualify semantics or enable any learner consumer.
