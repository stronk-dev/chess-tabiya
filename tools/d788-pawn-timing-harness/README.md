# D788 pawn timing harness

Disposable Phase-2b research instrument. It measures a pinned candidate-majority convention,
moved-pawn lever creation/execution and retained three-edge timing on the shared authored and sealed
imported populations. It is not production code and emits no chess advice.

Run:

```sh
pnpm exec vitest run --config tools/d788-pawn-timing-harness/vitest.config.ts
```
