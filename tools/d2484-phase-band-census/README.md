# D2484 phase-band census

Disposable Q4c research instrument. It walks the same legal authored-position population as
`make phase-classifier-census`, reconstructs the exact decision arm selected by the shipped phase
convention, and measures integer distance from each declared threshold.

Run:

```sh
make phase-band-census
```

The generated report is `planning/phase-band-census/results.json`. Distances are deterministic
operand units, not probabilities or calibrated confidence. This tool changes no product
classifier, evidence schema, pack, or authored chess statement.
