# D2485 phase-source composition census

Disposable Q4c research prototype. It walks every authored node and root-to-leaf path while keeping
four current evidence sources separate:

- exact opening endpoint and catalogue-path membership;
- the rules-only phase reading plus D2484 decision arm;
- the current rules endgame classifier; and
- committed recorded-tablebase availability versus local Syzygy domain.

Run `make phase-source-composition-census`. The report is
`planning/phase-source-composition/results.json`.

The prototype deliberately emits no merged “true phase,” relevance rank, theory advice or product
projection. Recorded absence is not relabelled provider failure. No production module imports this
tool.
