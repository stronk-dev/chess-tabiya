# Candidate-packet eleventh author repair

Disposable executable author model for D2860–D2863. It composes the tenth
author checkpoint with the current packet identity, terminal-state,
collector-outcome, abstention, asynchronous service, single-flight, bounded
queue, deadline, cancellation, cache and close contracts.

It is evidence for the RFC and is not production code. Run it through:

```sh
make candidate-packet-eleventh-author-repair
```
