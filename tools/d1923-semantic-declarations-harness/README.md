# D1923 semantic-declaration source recovery

Disposable exploration instrument under RFC-0000. It joins the stable 39-member seed to the live
compiled manifest and implementation witnesses, and verifies the stable literal 39-row declaration
population is set-equal to the seed with resolvable sources, definitions and limitations. The
population migrates shipped contracts at a pinned snapshot; it is not production code and does not
invent a new predicate or learner lesson.

```sh
pnpm exec vitest run --config tools/d1923-semantic-declarations-harness/vitest.config.ts
```
