# R7 Review Map harness

Disposable, read-only research instrument. It audits the shipped `review.story` consumer, Story
selector, private/public eight-moment bounds, social-card provenance and per-moment action doors. It
also runs one exact castling edge through both F2 and Story to prove that the new semantic event path
does not enter Review merely because F2 exists.

This harness does not define product moment eligibility, grade a move, run an engine, or authorize
F6. Run:

```sh
pnpm exec vitest run --config tools/r7-review-map-harness/vitest.config.ts
```
