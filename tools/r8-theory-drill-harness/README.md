# R8 theory↔drill join audit

Disposable, read-only platform-alignment research instrument. It inventories stable identities in
the authored corpus and checks whether the current learner surfaces preserve them across:

- pack → shape/principle/opening evidence;
- detected shape → matching pack recommendation;
- theory/library → playable drill;
- Review moment → theory/drill action.

The harness does not judge whether a theory passage applies, create a semantic join, or authorize
production code. Run:

```sh
pnpm exec vitest run --config tools/r8-theory-drill-harness/vitest.config.ts
```

`audit-output.md` is generated from the current tree.

`prototype.test.ts` is the fixed-position contract experiment. It resolves exact shape,
opening/transposition and anchored claim identities; excludes prospective shape references;
preserves the source run/node; and treats theory-without-a-pack and candidate-only opening coverage
as honest non-launchable results. It does not rank or infer applicability from text.
