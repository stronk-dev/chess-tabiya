# D815 threat-salience harness

Disposable research instrument for
`planning/platform-alignment/bot-policy/d815-salience-plan.md`. It measures whether exact threat
recency adds out-of-pack predictive value over engine-priced choice breadth. It neither registers a
production projection nor assigns a salience or quality label to a learner move.

Run the synthetic controls:

```sh
pnpm exec vitest run --config tools/d815-salience-harness/vitest.config.ts
```

Run the predeclared population measurement against the retained R11 inputs:

```sh
TABIYA_D815_INPUT_DIR=/private/tmp/d815-bot.example \
TABIYA_D815_WRITE=1 \
  pnpm exec vitest run --config tools/d815-salience-harness/vitest.config.ts
```

The input directory must contain `positions.json`, `probe-set.json`, `san-map.json`, and
`sf-d12.jsonl` as regenerated by `tools/maia-wdl-agreement-harness/README.md`. Aggregate output is
written to `tools/d815-salience-harness/out/summary.json`; raw inputs and per-position rows are not
committed.
