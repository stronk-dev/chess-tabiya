# D1921 semantic-convention product review harness

Disposable buildability instrument under `rfc/0000-rfc-process.md` §Exploration gate. It probes
the proposed value-level convention receipt, instance-operand validation, provider limitation
guard, previous-snapshot authority, durable history, and initial declaration population. It is not
production code.

Run from the repository root:

```sh
pnpm exec vitest run --config tools/d1921-semantic-convention-review-harness/vitest.config.ts
```
