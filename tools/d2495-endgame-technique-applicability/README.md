# D2495 endgame-technique applicability census

Disposable Q4c/D2487 research instrument. It walks the committed authored position corpus and
records only source-bounded KRPKR geometry operands plus three canonical-setup intersections.

It does not decide that a position “is” Lucena, Philidor or Vancura, does not infer a method from a
tablebase outcome, and does not propose moves. The canonical predicates are deliberately narrower
than the family names used by some sources; they exist to measure how far the shipped material-only
labels overreach and to supply symmetry/hard-negative fixtures for a future declared convention.

Run `make endgame-technique-applicability-census`. The report is
`planning/endgame-technique-applicability/results.json`.
