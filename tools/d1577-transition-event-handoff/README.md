# D1577 transition-event hand-off harness

Disposable research instrument. It asks whether the newer identity-preserving transition-event
layer can reconstruct the six older count-only transition families over every committed corpus
edge. It does not decide learner significance or authorize production changes.

Run:

```sh
./node_modules/.bin/vitest run --config tools/d1577-transition-event-handoff/vitest.config.ts
```

The test requires edge-by-edge equality for the five geometry families. For legacy
`move_irreversibility`, it checks that independent `castled`, `clock_reset`, `last_of_role`,
`pawn_contact` and pawn-`capture` events reconstruct all four old leaves without retaining the old
priority bucket as a learner-facing authority. It separately proves the old observations remain
square-empty while every new fact retains its required subject/from/to identities.
