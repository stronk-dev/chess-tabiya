# D4227 — scoped core feasibility

Disposable research tooling, not a candidate source, factory or production API. Appended code
calls the existing private legal enumeration, child application, foundation acquisition and
source validation. A guarded clone of the actual outcome algebra accepts the plain core data;
its receipt and unrelated collector-failure authentication obligations are explicitly **unclaimed**.
The original functions and on-disk production sources remain unchanged.

The question is whether all thirteen raw outcome payloads, literal input vectors/receipts and
complete quiet/positive populations can be reproduced from that core. It does not establish
equivalent full source coverage or qualify a new factory. Real receipt/factory readers must
refuse the raw frame. A future accepted contract must own requested/not-requested/failure
semantics and full on-demand event/reading collection through a single source owner.

Run from the repository root:

```sh
make core-acquisition-smoke
make core-acquisition-measure
```

The timed arms both acquire and compute all thirteen **raw** families; neither arm mints or
admits outcome events. Full acquisition uses the real64-entry application service. The raw arm
retains the same number of research frames and does not implement a production service/cache.
Fresh paired workers alternate order. These are local feasibility intervals and optional
forced-GC observations, not DOM/API latency, a Review budget certificate or appliance memory.
Only compact equality/count/timing summaries are retained; no raw payload/profile recording.
