# R3 evidence-presentation harness

**Disposable exploration instrument.** This is not production code and does not authorize an
assistance implementation. It answers only platform-alignment R3's mechanical arms.

The source census checks the shipped assistance settings, in-run evidence controls, ambient
affordance, board-lighting selector and LLM packet boundary. The corpus arm reproduces the current
board-lighting query over every occupied square in every unique authored-spine position and reports
caption/mark volume.

The module contract is a boundary prototype, not UI copy. It makes intent, timing, activation,
consumer eligibility, fact budget and recommendation permission explicit. Synthetic fixtures test
zero/one/many facts, abstention, later-rung leakage, consumer mismatch and move/PV leakage without
manufacturing chess claims. Owner ruling D619 now permits `sight_on_request` before commitment
without ranking a move. It remains a research candidate until R3 validates the workflow; the ruling
does not convert this disposable harness into product authority.

`real-packet.ts` is the post-F2 bridge the original prototype could not contain. It accepts only a
runtime-sealed `EvidenceSelectionResult`, preserves its exact event IDs, operands, alternative
population, signs and squares, and renders neutral fact text. The three committed fixtures are
regenerated by `real-packet.test.ts`; a structurally similar object is rejected. These are real
compiler-admitted rule facts, but their mapping to R3 modules remains an explicitly disposable
research binding rather than production eligibility.

`workflow-contract.ts` and `prototype.html` make the participant protocol executable. The prototype
separates six learning workflows from five assistance presets, includes the D619 Support-only warning
boundary, applies suppressive session ceilings, preserves Theory only, exposes every module in an
advanced disposition view and distinguishes an empty result from an unavailable provider. All
chess-like copy is explicitly synthetic fixture text.

This harness cannot answer whether nontechnical chess players understand the candidate modules or
defaults. D537/D573 and accessible-board-input repaired the earlier interaction blocker; the remaining
R3 exit is owner use with these real packets, not another synthetic or source-control pass.

Run:

```sh
pnpm exec vitest run --config tools/r3-presentation-harness/vitest.config.ts
```

To inspect the static prototype locally:

```sh
python3 -m http.server 4174 --directory tools/r3-presentation-harness
```

Then open `http://127.0.0.1:4174/prototype.html`. Do not serve or ship this artifact as product UI.
