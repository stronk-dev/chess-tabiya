# D1164 novelty identity harness

Disposable research instrument for D1164, D1693 and D1694. It derives the proactive-module
projection closure from the literal accepted sets, supplies one stable-field or explicit-exemption
row for every possible member, and proves node/move anchors do not define novelty.

It intentionally derives two active cardinalities: 49 when the on-request theory breadcrumb uses
window 0, and 52 if an author amendment makes that module suppressible. The harness does not choose
that product semantic.

Run with Node 24:

```sh
/opt/homebrew/opt/node@24/bin/node node_modules/vitest/vitest.mjs run \
  --config tools/d1164-novelty-identity-harness/vitest.config.ts
```
