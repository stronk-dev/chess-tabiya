# R20 grounded skills-taxonomy desk instrument

Disposable research under RFC-0000's exploration gate. It closes every current
`SEMANTIC_EVENT_PROJECTION_IDS` member into a skills category and one of four dispositions, then
checks the small set of candidate credits for a complete declinable-opportunity rule. It does not
register product skill ids, set production thresholds or write learner data.

Run:

```sh
pnpm exec vitest run --config tools/r20-skills-taxonomy/vitest.config.ts
```

The output is `output.md`. A green desk arm is permitted to report zero production-ready credits;
the longitudinal/reference-population measurement is deliberately a separate arm.
