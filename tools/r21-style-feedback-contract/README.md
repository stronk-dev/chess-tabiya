# R21 longitudinal style-feedback contract instrument

Disposable research under RFC-0000's exploration gate. It joins every persistently retained R12
habit metric to its exact input, denominator, measured short-session floor, production evidence
gap, shared bot/style feature atom and permitted presentation. It does not register production
metrics, create a learner profile or authorize thresholds.

Run:

```sh
pnpm exec vitest run --config tools/r21-style-feedback-contract/vitest.config.ts
```

The test reads the committed R12 result directly and emits `output.md`. Green means the desk
contract is complete and honest about its blockers; it does not mean any metric is production-ready.
