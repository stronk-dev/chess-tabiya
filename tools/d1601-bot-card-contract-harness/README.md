# D1601/D1607 bot card contract harness

Disposable contract instrument for independently declared bot axes and mechanically grounded
profile cards. It does not choose the twelve persona names or art.

Run with Node 24:

```sh
/opt/homebrew/opt/node@24/bin/node node_modules/vitest/vitest.mjs run \
  --config tools/d1601-bot-card-contract-harness/vitest.config.ts
```
