# D3059 provider-health cut contract

This bounded governance check replaces the retired twelve-round author-model chain in canonical CI.
The historical `provider-health-*` targets remain runnable, but they intentionally describe earlier
RFC images and are not acceptance authority for the 2026-09-06 cut.

The contract checks only the surviving boundary: a claim-free live-health RFC, its closed public
identity/state/cache surfaces, twenty-two row-backed implementation criteria, and the separately
registered run-schema successor.

Run with `make provider-health-cut-contract`.
